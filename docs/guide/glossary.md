# Glossary

| Term                    | Meaning                                                                                                                                             | See                                                     |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| A-label                 | The ASCII form of an IDN label: `xn--` plus Punycode, such as `xn--mnchen-3ya`                                                                      | [3.2](03-domains/02-idn-and-punycode.md)                |
| ACE prefix              | `xn--`, marking a label as ASCII Compatible Encoding                                                                                                | [3.2](03-domains/02-idn-and-punycode.md)                |
| ASCII                   | The 128-character table (0-127) that Unicode and UTF-8 start with                                                                                   | [1.2](01-foundations/02-ascii.md)                       |
| Augmented script set    | Scripts that legitimately appear together, such as Han + Hiragana + Katakana for Japanese                                                           | [2.3](02-tricky-unicode/03-confusables-and-scripts.md)  |
| Bidi control            | Invisible character that changes text direction (U+202A-U+202E, U+2066-U+2069, U+200E-U+200F)                                                       | [2.4](02-tricky-unicode/04-bidirectional-text.md)       |
| Block                   | A named, contiguous range of code points, such as General Punctuation (U+2000-U+206F)                                                               | [1.3](01-foundations/03-unicode.md)                     |
| BMP                     | Basic Multilingual Plane, U+0000-U+FFFF                                                                                                             | [1.3](01-foundations/03-unicode.md)                     |
| BOM                     | Byte order mark, U+FEFF at the start of a file                                                                                                      | [1.4](01-foundations/04-encoding-and-decoding.md)       |
| Bootstring              | The general algorithm Punycode is an instance of                                                                                                    | [3.2](03-domains/02-idn-and-punycode.md)                |
| Byte                    | 8 bits, values 0-255                                                                                                                                | [1.1](01-foundations/01-bits-bytes-and-numbers.md)      |
| Case folding            | Mapping for case-insensitive comparison (`ß` folds to `ss`)                                                                                         | [2.2](02-tricky-unicode/02-normalization.md)            |
| Code point              | The number Unicode assigns to a character, written `U+XXXX`                                                                                         | [1.3](01-foundations/03-unicode.md)                     |
| Code unit               | The storage unit of an encoding: 8 bits in UTF-8, 16 bits in UTF-16                                                                                 | [1.4](01-foundations/04-encoding-and-decoding.md)       |
| Confusable / homoglyph  | A character that looks like another, such as Cyrillic `а` and Latin `a`                                                                             | [2.3](02-tricky-unicode/03-confusables-and-scripts.md)  |
| Decoding                | Turning bytes into text using an encoding                                                                                                           | [1.4](01-foundations/04-encoding-and-decoding.md)       |
| Default ignorable       | Unicode property for code points that should render as nothing when unsupported; covers zero-width, bidi, Hangul fillers, tags, variation selectors | [2.1](02-tricky-unicode/01-invisible-characters.md)     |
| Encoding                | Turning text into bytes (UTF-8, UTF-16, ...); also the name of such a scheme                                                                        | [1.4](01-foundations/04-encoding-and-decoding.md)       |
| Escape                  | A way of writing a character with visible ASCII, such as `\u3164`, `&#x3164;`, `%E3%85%A4`                                                          | [1.5](01-foundations/05-escapes-and-representations.md) |
| General category        | Two-letter character class, such as `Lu`, `Cf`, `Co`                                                                                                | [1.3](01-foundations/03-unicode.md)                     |
| Grapheme cluster        | What a reader perceives as one character, possibly several code points                                                                              | [1.3](01-foundations/03-unicode.md)                     |
| Hangul filler           | U+115F, U+1160, U+3164, U+FFA0: blank characters categorized as letters                                                                             | [2.1](02-tricky-unicode/01-invisible-characters.md)     |
| Hexadecimal             | Base 16, digits 0-9 and A-F; two hex digits are one byte                                                                                            | [1.1](01-foundations/01-bits-bytes-and-numbers.md)      |
| Homograph attack        | Using confusable characters to imitate a trusted name                                                                                               | [3.3](03-domains/03-homograph-attacks.md)               |
| IDN                     | Internationalized Domain Name, a domain with non-ASCII labels                                                                                       | [3.2](03-domains/02-idn-and-punycode.md)                |
| IDNA2003 / IDNA2008     | The two generations of IDN standards                                                                                                                | [3.2](03-domains/02-idn-and-punycode.md)                |
| Label                   | One dot-separated part of a hostname                                                                                                                | [3.1](03-domains/01-domain-names.md)                    |
| LDH                     | Letters, digits, hyphen: the classic hostname character rule                                                                                        | [3.1](03-domains/01-domain-names.md)                    |
| Mixed-script            | A string, usually one label or identifier, using letters from more than one script                                                                  | [2.3](02-tricky-unicode/03-confusables-and-scripts.md)  |
| Mojibake                | Garbled text from decoding with the wrong encoding                                                                                                  | [1.4](01-foundations/04-encoding-and-decoding.md)       |
| NFC, NFD, NFKC, NFKD    | The four Unicode normalization forms                                                                                                                | [2.2](02-tricky-unicode/02-normalization.md)            |
| Plane                   | One of 17 groups of 65,536 code points                                                                                                              | [1.3](01-foundations/03-unicode.md)                     |
| Private Use Area (PUA)  | Code points with no standard meaning: U+E000-U+F8FF and planes 15-16                                                                                | [2.1](02-tricky-unicode/01-invisible-characters.md)     |
| Public suffix           | A suffix under which anyone can register names, such as `com`, `co.uk`, `github.io`                                                                 | [3.1](03-domains/01-domain-names.md)                    |
| Punycode                | The encoding (RFC 3492) that turns a Unicode label into ASCII                                                                                       | [3.2](03-domains/02-idn-and-punycode.md)                |
| Registrable domain      | Public suffix plus one label (eTLD+1): who owns a site                                                                                              | [3.1](03-domains/01-domain-names.md)                    |
| Script                  | The writing system a character belongs to (Latin, Cyrillic, Han, ...)                                                                               | [1.3](01-foundations/03-unicode.md)                     |
| Skeleton                | A string with every confusable replaced by a prototype; equal skeletons mean "looks the same"                                                       | [2.3](02-tricky-unicode/03-confusables-and-scripts.md)  |
| Surrogate pair          | Two UTF-16 code units (U+D800-U+DFFF) encoding one code point above U+FFFF                                                                          | [1.4](01-foundations/04-encoding-and-decoding.md)       |
| Tag characters          | U+E0000-U+E007F, invisible copies of ASCII                                                                                                          | [2.1](02-tricky-unicode/01-invisible-characters.md)     |
| Trojan Source           | Using bidi controls so code displays differently than it executes (CVE-2021-42574)                                                                  | [2.4](02-tricky-unicode/04-bidirectional-text.md)       |
| U-label                 | The Unicode form of an IDN label, such as `münchen`                                                                                                 | [3.2](03-domains/02-idn-and-punycode.md)                |
| UTF-8, UTF-16, UTF-32   | Unicode encodings with 8-, 16-, and 32-bit code units                                                                                               | [1.4](01-foundations/04-encoding-and-decoding.md)       |
| UTS #39                 | Unicode Security Mechanisms: confusables, skeletons, restriction levels                                                                             | [2.3](02-tricky-unicode/03-confusables-and-scripts.md)  |
| UTS #46                 | Unicode IDNA Compatibility Processing: how browsers map and validate domain names                                                                   | [3.2](03-domains/02-idn-and-punycode.md)                |
| Variation selector      | U+FE00-U+FE0F, U+E0100-U+E01EF: choose a glyph variant of the previous character                                                                    | [2.1](02-tricky-unicode/01-invisible-characters.md)     |
| Whole-script confusable | A label written entirely in another script that looks like a Latin word, such as `аррӏе`                                                            | [2.3](02-tricky-unicode/03-confusables-and-scripts.md)  |
| Zero-width character    | U+200B, U+200C, U+200D, U+2060, U+FEFF: characters with no width                                                                                    | [2.1](02-tricky-unicode/01-invisible-characters.md)     |
