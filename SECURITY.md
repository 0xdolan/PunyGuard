# Security Policy

## Supported versions

Only the latest release on each store receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems, including detection bypasses that let a lookalike domain pass as safe.

Report privately through [GitHub private vulnerability reporting](https://github.com/0xdolan/PunyGuard/security/advisories/new). Include the browser and PunyGuard version (shown in the popup footer), the hostname or page involved, and steps to reproduce.

You can expect an acknowledgement within 7 days. Fixes ship as a patch release and are credited in the changelog unless you prefer otherwise.
